개인정보 처리방침

소복소복 · 최종 수정일: 2026년 10월 23일

소복소복은 계정을 만들지 않으며, 일기·감정·사진·작품 감상을 개발사 서버로 전송하거나 수집하지 않습니다.

기기에 저장하는 정보

  • 일기 제목과 본문
  • 선택한 감정, 날짜, 별점, 소중한 기록 여부
  • 사용자가 선택한 사진의 앱 전용 복사본
  • 사용자가 선택한 책·영화의 제목, 제작자, 연도, 외부 링크
  • 작성 중인 임시 초안과 기기 잠금 사용 여부
  • 하루 알림 사용 여부와 알림 시각
  • 소복소복 플러스 구매 여부와 마지막 확인 시각

이 정보는 기기 내부의 SQLite 데이터베이스, 앱 문서 폴더, 운영체제 preferences에 저장됩니다. 앱을 삭제하면 운영체제 정책에 따라 함께 삭제될 수 있으므로, 필요한 경우 미리 백업을 내보내야 합니다.

운영체제 백업

사용자의 iOS 또는 Android 백업 설정에 따라 앱 데이터가 운영체제가 제공하는 암호화된 기기 백업이나 기기 간 이전에 포함될 수 있습니다. 소복소복은 이 백업을 별도 서버에서 받거나 열람하지 않으며, 포함 여부와 보관 기간은 사용자의 운영체제 계정 및 기기 설정을 따릅니다.

구매

소복소복 플러스는 App Store 또는 Google Play 결제로 구매합니다. 결제는 Apple·Google이 처리하며, 앱은 구매 여부와 마지막 확인 시각만 기기에 저장합니다. 개발사는 결제 정보나 구매 내역을 받지 않습니다.

네트워크 사용

사용자가 책 또는 영화를 검색할 때에만 검색어가 Wikidata 질의 서비스로 전송됩니다. 소복소복은 검색어, 검색 결과, 이용 행동을 어떤 서버에도 기록하지 않습니다. 작품 검색과 스토어 결제 외에는 앱이 네트워크를 사용하지 않으며, 일기 내용은 어떤 경우에도 전송하지 않습니다.

권한

  • 사진 보관함: 사용자가 고른 사진을 일기에 첨부할 때만 사용합니다.
  • Face ID·지문·기기 암호: 사용자가 기기 잠금을 켠 경우 기기 안에서 인증할 때만 사용합니다.
  • 알림: 사용자가 하루 알림을 켤 때만 요청합니다. 알림은 기기 안에서 예약되며 서버나 푸시 서비스를 거치지 않고, 알림 문구에는 일기 내용이 들어가지 않습니다.
  • 인터넷: 사용자가 책·영화를 검색할 때만 사용합니다.

내보내기

사용자가 요청하면 전체 기록과 앱 전용 사진을 ZIP 파일로 만듭니다. 파일의 저장 위치와 전송 대상은 운영체제 공유 시트에서 사용자가 직접 선택합니다.

제3자 SDK

광고, 행동 분석, 원격 오류 수집 SDK를 포함하지 않습니다. 작품 검색에는 위키미디어 재단이 운영하는 Wikidata 질의 서비스를 사용하며, 계정이나 API 키 없이 호출합니다.

아동의 개인정보

소복소복은 아동을 주 대상으로 하지 않으며, 나이를 포함한 어떤 개인정보도 수집하지 않습니다.
