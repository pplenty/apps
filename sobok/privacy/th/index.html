นโยบายความเป็นส่วนตัว

Sobok · อัปเดตล่าสุด: 23/10/2026

Sobok ไม่มีระบบบัญชีผู้ใช้ ไดอารี่ ความรู้สึก รูปภาพ และบันทึกเกี่ยวกับหนังสือและหนังของคุณจะไม่ถูกส่งไปให้ผู้พัฒนา และผู้พัฒนาไม่เก็บรวบรวมข้อมูลเหล่านี้

ข้อมูลที่จัดเก็บในอุปกรณ์ของคุณ

  • ชื่อเรื่องและข้อความของบันทึก
  • ความรู้สึก วันที่ และคะแนนที่คุณเลือก รวมถึงสถานะว่าบันทึกเป็นรายการโปรดหรือไม่
  • สำเนารูปภาพที่คุณเลือก ซึ่งใช้เฉพาะในแอป
  • ชื่อเรื่อง ผู้สร้าง ปี และลิงก์ของหนังสือและหนังที่คุณเลือก
  • ฉบับร่างที่ยังเขียนไม่เสร็จ และสถานะว่าเปิดล็อกแอปอยู่หรือไม่
  • สถานะว่าเปิดการแจ้งเตือนรายวันอยู่หรือไม่ และเวลาที่ตั้งไว้
  • สถานะว่าซื้อ Sobok Plus แล้วหรือไม่ และเวลาที่ยืนยันครั้งล่าสุด

ข้อมูลเหล่านี้เก็บไว้ในฐานข้อมูล SQLite โฟลเดอร์เอกสารของแอป และการตั้งค่าของระบบบนอุปกรณ์ของคุณ การลบแอปอาจลบข้อมูลเหล่านี้ไปด้วย ขึ้นอยู่กับระบบปฏิบัติการ หากต้องการเก็บไว้ โปรดส่งออกข้อมูลสำรองก่อน

การสำรองข้อมูลของระบบปฏิบัติการ

ข้อมูลแอปอาจรวมอยู่ในข้อมูลสำรองของอุปกรณ์แบบเข้ารหัส หรือการย้ายข้อมูลระหว่างอุปกรณ์ที่ระบบปฏิบัติการมีให้ ขึ้นอยู่กับการตั้งค่าการสำรองข้อมูลของ iOS หรือ Android Sobok ไม่ได้รับหรืออ่านข้อมูลสำรองเหล่านี้บนเซิร์ฟเวอร์ใดๆ ข้อมูลสำรองจะรวมแอปไว้หรือไม่ และเก็บไว้นานเท่าใด เป็นไปตามการตั้งค่าบัญชีระบบและอุปกรณ์ของคุณ

การซื้อ

Sobok Plus ซื้อผ่าน App Store หรือ Google Play การชำระเงินดำเนินการโดย Apple หรือ Google แอปเก็บไว้ในอุปกรณ์เพียงสถานะว่าซื้อแล้วหรือไม่ และเวลาที่ยืนยันครั้งล่าสุดเท่านั้น ผู้พัฒนาไม่ได้รับรายละเอียดการชำระเงินหรือประวัติการซื้อใดๆ

การใช้เครือข่าย

เฉพาะเมื่อคุณค้นหาหนังสือหรือหนัง คำค้นหาจะถูกส่งไปยัง Wikidata Query Service Sobok ไม่บันทึกคำค้นหา ผลการค้นหา หรือข้อมูลการใช้งานแอปไว้บนเซิร์ฟเวอร์ใดๆ นอกจากการค้นหาดังกล่าวและการชำระเงินผ่านสโตร์ แอปไม่ใช้เครือข่าย และไม่ส่งเนื้อหาไดอารี่ออกไปเลย

สิทธิ์การเข้าถึง

  • คลังรูปภาพ: เฉพาะเมื่อคุณแนบรูปที่เลือกไว้กับบันทึก
  • Face ID ลายนิ้วมือ หรือรหัสผ่าน: เฉพาะเพื่อยืนยันตัวตนบนอุปกรณ์เมื่อคุณเปิดล็อกแอป
  • การแจ้งเตือน: ขออนุญาตเฉพาะเมื่อคุณเปิดการแจ้งเตือนรายวัน การแจ้งเตือนตั้งเวลาไว้บนอุปกรณ์โดยไม่ใช้เซิร์ฟเวอร์หรือบริการพุชใดๆ และไม่มีเนื้อหาไดอารี่
  • อินเทอร์เน็ต: เฉพาะเมื่อคุณค้นหาหนังสือหรือหนัง

การส่งออก

เมื่อคุณสั่ง แอปจะสร้างไฟล์ ZIP ของบันทึกทั้งหมดพร้อมรูปภาพ คุณเลือกเองว่าจะบันทึกหรือส่งไปที่ใดผ่านหน้าต่างแชร์ของระบบ

SDK ของบุคคลที่สาม

ไม่มี SDK สำหรับโฆษณา การวิเคราะห์ หรือการรายงานข้อขัดข้องจากระยะไกล การค้นหาหนังสือและหนังใช้ Wikidata Query Service ซึ่งดำเนินการโดย มูลนิธิวิกิมีเดีย (Wikimedia Foundation) โดยเรียกใช้โดยไม่มีบัญชีหรือคีย์ API

เด็ก

Sobok ไม่ได้มุ่งเป้าไปที่เด็ก และไม่เก็บข้อมูลส่วนบุคคลใดๆ รวมถึงอายุ
