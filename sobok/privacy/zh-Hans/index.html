隐私政策

Sobok · 最后更新：2026年10月23日

Sobok 没有账号。你的日记、心情、照片以及对书和电影的感想，都不会发送给开发者，也不会被开发者收集。

保存在你设备上的内容

  • 记录的标题和正文
  • 你选择的心情、日期和评分，以及记录是否已收藏
  • 你所选照片在应用内的副本
  • 你所选书和电影的标题、作者或导演、年份和链接
  • 未写完的草稿，以及应用锁是否开启
  • 每日提醒是否开启，以及提醒时间
  • 是否已购买 Sobok Plus，以及最后一次确认的时间

这些内容保存在你设备上的 SQLite 数据库、应用的文档文件夹和系统偏好设置中。 视操作系统而定，删除应用时这些数据可能会一并删除；如有需要，请先导出备份。

操作系统备份

视你的 iOS 或 Android 备份设置而定，应用数据可能会包含在操作系统提供的加密设备备份或设备间迁移中。 Sobok 不会在任何服务器上接收或读取这些备份；备份是否包含本应用以及保留多久，取决于你的系统账号和设备设置。

购买

Sobok Plus 通过 App Store 或 Google Play 购买。付款由 Apple 或 Google 处理；应用只在设备上保存是否已购买，以及最后一次确认的时间。 开发者不会收到任何付款信息或购买记录。

网络使用

只有在你搜索书或电影时，搜索词才会发送到 Wikidata Query Service。 Sobok 不会在任何服务器上记录搜索词、搜索结果或你的使用情况。 除了这项搜索和应用商店付款之外，应用不使用网络，也绝不会发送日记内容。

权限

  • 照片图库：仅在你把选好的照片附加到记录时使用。
  • 面容 ID、指纹或锁屏密码：仅在你开启应用锁后，用于在设备上验证身份。
  • 通知：仅在你开启每日提醒时请求。提醒在设备上安排，不经过任何服务器或推送服务，也绝不包含日记内容。
  • 网络：仅在你搜索书或电影时使用。

导出

应你的要求，应用会把所有记录及其照片打包成一个 ZIP 文件。保存或发送到哪里，由你在系统分享菜单中选择。

第三方 SDK

不含任何广告、分析或远程崩溃报告 SDK。书和电影搜索使用由维基媒体基金会运营的 Wikidata Query Service，调用时不使用账号或 API 密钥。

儿童

Sobok 并非面向儿童，也不收集包括年龄在内的任何个人信息。

联系我们

有关隐私的问题：sobok@jdgrid.com。

政策变更

本政策变更时，顶部的日期会随之更新；凡是收集或发送的内容有所变更，也会在应用更新说明中告知。
