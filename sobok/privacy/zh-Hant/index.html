隱私權政策

Sobok · 最後更新：2026年10月23日

Sobok 沒有帳號。你的日記、心情、照片與書和電影的心得，都不會傳送給開發者，也不會被收集。

儲存在裝置上的資訊

  • 日記的標題與內文
  • 選擇的心情、日期、評分，以及是否加入收藏
  • 你選擇的照片在 App 內的副本
  • 你選擇的書和電影的標題、作者或導演、年份、外部連結
  • 寫到一半的草稿，以及是否開啟 App 鎖定
  • 是否開啟每日提醒與提醒時間
  • 是否已購買 Sobok Plus，以及最後確認的時間

這些資訊存放在裝置內的 SQLite 資料庫、App 的文件資料夾與系統偏好設定中。 依作業系統規定，刪除 App 時這些資料可能一併刪除，必要時請先匯出備份。

作業系統備份

依你的 iOS 或 Android 備份設定，App 資料可能包含在作業系統提供的加密裝置備份或裝置間轉移中。 Sobok 不會在任何伺服器上接收或讀取這些備份；是否包含與保存期限依你的系統帳號與裝置設定而定。

購買

Sobok Plus 透過 App Store 或 Google Play 付款購買。付款由 Apple 或 Google 處理，App 只在裝置上保存是否已購買與最後確認的時間。 開發者不會收到付款資訊或購買紀錄。

網路使用

只有在搜尋書或電影時，搜尋字詞才會傳送到 Wikidata Query Service。 Sobok 不會在任何伺服器上記錄搜尋字詞、搜尋結果或使用行為。 除了作品搜尋與商店付款之外，App 不使用網路，也絕不傳送日記內容。

權限

  • 照片圖庫：只在把你選的照片附加到日記時使用。
  • Face ID、指紋或裝置密碼：只在你開啟 App 鎖定後，於裝置上驗證時使用。
  • 通知：只在你開啟每日提醒時請求。提醒在裝置上排程，不經過伺服器或推播服務，內容也不包含日記。
  • 網路：只在搜尋書或電影時使用。

匯出

在你要求時，App 會把所有紀錄與照片做成 ZIP 檔。儲存位置與傳送對象由你在系統分享選單中自行選擇。

第三方 SDK

不包含廣告、行為分析或遠端錯誤回報 SDK。作品搜尋使用維基媒體基金會營運的 Wikidata Query Service，不需帳號或 API 金鑰。

兒童隱私

Sobok 並非以兒童為主要對象，也不收集包括年齡在內的任何個人資訊。

聯絡我們

隱私相關問題請寄信至 sobok@jdgrid.com。

政策變更

本政策變更時會更新上方日期；若收集或傳送的範圍有所改變，也會在 App 更新說明中告知。
