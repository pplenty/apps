Où mon journal est-il stocké ?

Uniquement sur votre appareil. Il n’y a ni compte ni serveur : le développeur ne peut donc pas voir votre journal. Consultez la politique de confidentialité.

Mes entrées me suivront-elles sur un nouveau téléphone ?

Elles suivent la sauvegarde ou le transfert d’appareil du système d’exploitation, lorsque ceux-ci incluent les données des apps. Par précaution, créez d’abord une sauvegarde ZIP avec Exporter une sauvegarde dans les Réglages. Le fichier diary.json qu’elle contient est lisible tel quel.

Puis-je récupérer une sauvegarde ?

Oui. Choisissez le ZIP exporté dans Importer une sauvegarde, dans les Réglages. L’import fusionne : rien n’est supprimé de l’appareil, la version d’une entrée modifiée le plus récemment l’emporte, les entrées présentes uniquement dans la sauvegarde sont ajoutées, et les photos reviennent aussi.

Que se passe-t-il si je supprime l’app ?

Selon le système d’exploitation, les données de l’app peuvent être supprimées avec elle : exportez d’abord une sauvegarde. Une fois votre journal bien rempli, les Réglages vous indiquent combien d’entrées vous avez écrites depuis votre dernière sauvegarde.

Un livre ou un film n’apparaît pas dans la recherche

La recherche nécessite une connexion Internet. Si l’œuvre n’y figure pas, ajoutez vous-même son titre et son auteur ou réalisateur depuis l’écran de recherche.

Le verrouillage de l’app ne s’active pas

Votre appareil doit d’abord avoir Face ID, une empreinte digitale ou un code de verrouillage de l’écran configuré.

Comment restaurer mon achat ?

Sobok Plus reste lié à votre compte Apple ou Google. Sur un appareil connecté au même compte, touchez Restaurer l’achat dans les Réglages.
