개인정보 처리방침

글쓰기냥 · 시행일: 2026년 9월 28일

글쓰기냥은 사용자가 쓴 글을 사적으로 지키도록 설계되었습니다. 앱은 개인정보를 개발자나 제3자에게 수집, 전송, 판매 또는 공유하지 않습니다.

1. 기기에 저장되는 데이터

글, 초안, 글감 이력, 즐겨찾기, 생선 잔액, 고양이, 소품, 연속 기록, 설정은 모두 사용자의 기기에 저장됩니다. 개발자 서버가 없으므로 개발자는 이 데이터를 보거나 복구할 수 없습니다.

사용자의 기기 백업 설정에 따라 운영체제가 앱 데이터를 기기 백업에 포함할 수 있습니다. 해당 백업은 플랫폼 제공자와 사용자가 관리하며 개발자는 접근할 수 없습니다.

2. 내보내기와 복원

글을 마크다운 또는 JSON으로 내보내고, JSON 파일에서 글을 복원할 수 있습니다. 이 동작은 사용자가 직접 시작할 때만 실행됩니다. 저장할 곳과 불러올 파일은 운영체제 화면에서 사용자가 고릅니다. 내보낸 파일은 개발자에게 전송되지 않습니다.

다른 앱, 저장 공간 제공자, 공유 대상이 처리하는 파일에는 해당 제공자의 개인정보 처리방침이 적용됩니다.

3. 알림, 위젯, 구매

선택형 글쓰기 알림은 사용자의 기기에서 예약됩니다. 홈 화면 위젯은 같은 기기의 앱과 위젯만 사용하는 공유 저장 공간에서 오늘의 글감과 연속 기록을 읽습니다.

선택형 인앱 구입(특별 고양이 팩, 간식 후원)은 Apple 또는 Google이 각 사의 약관에 따라 처리합니다. 개발자는 사용자의 이름, 계정, 결제 정보를 받지 않습니다. 앱은 특별 고양이 팩의 해금 여부만 기기에 저장하고, '구매 복원'을 누르면 스토어에 복원을 요청합니다.

4. 권한

사용자가 알림을 켜면 알림 권한을 요청할 수 있습니다. Android에서는 켜 둔 로컬 알림을 기기 재시작 뒤 다시 예약하기 위해 재시작 완료 이벤트도 받습니다. 또한 Google Play 결제 라이브러리가 구매 처리와 구글로 보내는 자체 진단을 위해 네트워크 접근을 선언합니다. 앱 코드 자체는 개발자에게 아무것도 보내지 않습니다. 카메라, 마이크, 연락처, 위치, 광고 식별자, 사진 전체 접근 권한은 요청하지 않습니다.

5. 분석, 광고, 추적

광고, 사용 분석, 추적, 충돌 수집, 소셜 피드 서비스가 없습니다. 계정과 개발자 운영 네트워크 서비스도 사용하지 않습니다.

6. 데이터 삭제

앱 안에서 글을 하나씩 삭제할 수 있습니다. 앱을 삭제하면 사용자가 관리하는 기기 백업을 제외한 로컬 데이터가 삭제됩니다. 나중에 글을 복원하려면 먼저 JSON 백업을 내보내세요.

7. 아동의 개인정보

앱은 개인정보 자체를 수집하지 않으므로 아동을 포함한 누구의 개인정보도 의도적으로 수집하지 않습니다.

8. 처리방침 변경

앱의 데이터 처리 방식이 바뀌면 변경된 동작을 출시하기 전에 이 처리방침과 스토어 개인정보 공개 내용을 함께 수정합니다. 위 시행일도 갱신합니다.
